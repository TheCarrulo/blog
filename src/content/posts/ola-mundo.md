Bem-vindo ao **Carrulo in Bytes**.

Este é o primeiro post deste blog, que nasce com um propósito simples: partilhar ideias, aprendizagens e reflexões sobre tecnologia.

## O que esperar por aqui?

Ainda estou a definir os contornos exactos, mas a ideia geral passa por:

- **Artigos técnicos** — tutoriais, dicas e truques de programação
- **Reflexões** — pensamentos sobre a indústria, ferramentas e tendências
- **Projectos pessoais** — o que estou a construir e o que aprendi no processo

## A stack deste blog

Este blog foi construído com [Astro](https://astro.build/), um framework moderno para sites estáticos. A escolha foi deliberada:

- Zero JavaScript enviado ao browser por defeito
- Suporte nativo a Markdown para os posts
- Deploy simples no GitHub Pages
- Extremamente rápido

```bash
npm create astro@latest
```

A pesquisa é feita com **Pagefind**, que indexa o conteúdo estático sem precisar de servidor. Tudo corre no browser, sem dependências externas.

## Por que "Carrulo in Bytes"?

Porque é pessoal e porque tudo acaba sempre em bytes — sejam ideias, código ou histórias.

Até breve.
